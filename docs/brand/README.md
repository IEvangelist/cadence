# Brand kit (Phase 1)

Owned by the **Brand & Design** squad. Deliverables land here:

- `logo/` — primary logo, wordmark, responsive/adaptive marks (SVG)
- `color/` — palette + design tokens
- `type/` — typography scale + font choices
- `icon/` — iconography set
- `motion/` — motion guidelines
- `sonic/` — the audio logo / sonic identity
- `guidelines.md` — usage rules, the "hook", do/don't

Tokens exported here are consumed by both the app theme (`apps/web`) and the
GitHub Pages landing page.

# apps/desktop

Tauri (Rust) desktop shell wrapping `apps/web`. Cross-platform from day one.

**Requires the Rust toolchain** (`rustup`), which is not yet installed on the
build machine — the DevOps/Release squad provisions it. Pin the toolchain via
`rust-toolchain.toml` and commit `Cargo.lock`.

> Status: to be scaffolded (`npm create tauri-app@latest`).
